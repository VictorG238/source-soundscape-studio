# Changelog

## 0.1.0

- Edit Source 1 soundscapes visually or as KeyValues, with shared Undo and Redo and preservation of comments and duplicate keys.
- Preview loose audio and Source 1 VPK v1/v2 contents. Detect game and mod audio sources and show where each sound was found or searched for.
- Browse mounted sounds, audition with waveforms, add multiple random variants and preview inspector changes before applying or saving.
- Manage manifest load order, add or remove script registrations, and edit manifest source text.
- Build and package Windows x64 and Linux x64 using Docker.
- About displays the compiled version. Update settings support stable GitHub Release checks and manual downloads once the official repository is configured.
